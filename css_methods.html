Phần 1: Inline Style

Đây là cách thay đổi màu sắc sử dụng inline style. Chúng ta áp dụng CSS trực tiếp vào thẻ HTML bằng thuộc tính style. Ưu điểm: nhanh chóng và dễ dàng. Nhược điểm: khó quản lý khi có nhiều phần tử.

Phần 2: Internal Style

Đây là cách thay đổi màu sắc sử dụng internal style. Chúng ta định nghĩa CSS bên trong thẻ <style> trong phần <head>. Ưu điểm: dễ quản lý và có thể tái sử dụng. Nhược điểm: chỉ áp dụng cho một trang web duy nhất.

Phần 3: External Style

Đây là cách thay đổi màu sắc sử dụng external style. Chúng ta tạo một file CSS riêng biệt và kết nối vào trang HTML bằng thẻ <link>. Ưu điểm: dễ quản lý, có thể tái sử dụng cho nhiều trang. Nhược điểm: cần tải file CSS bổ sung.
