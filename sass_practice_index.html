Khám phá sức mạnh của SASS với Variables, Mixins, Nesting, và Responsive Design

Về SASS

SASS (Syntactically Awesome StyleSheets) là một CSS preprocessor giúp viết CSS một cách hiệu quả hơn. Nó hỗ trợ các tính năng như variables, mixins, nesting, functions, và nhiều hơn nữa.

Variables

Khai báo các biến màu, kích thước, font chữ để tái sử dụng trong toàn bộ stylesheet.

Mixins

Tạo các khối CSS tái sử dụng (reusable code blocks) để giảm lặp lại.

Nesting

Lồng các selector CSS giúp code dễ đọc và tổ chức hơn.

Functions

Sử dụng các hàm có sẵn như lighten(), darken(), rgba() để thao tác màu sắc.

Responsive Design

Media queries và mixins giúp tạo responsive design dễ dàng hơn.

Import

Chia nhỏ stylesheet thành nhiều file và import chúng vào một file chính.

Các Tính Năng Chính

1. Variables (Biến)

Các biến trong SASS giúp bạn lưu trữ các giá trị như màu sắc, font chữ, kích thước, độ rộng lề, v.v. Thay vì lặp lại các giá trị này trong mã CSS, bạn chỉ cần thay đổi giá trị của biến một lần.

$primary-color: #667eea;
$base-font: 'Segoe UI', sans-serif;
color: $primary-color;

2. Mixins (Hỗn hợp)

Mixins cho phép bạn tạo các khối CSS tái sử dụng. Chúng rất hữu ích cho các phần tử CSS phức tạp hoặc lặp lại như flexbox, transition, button variants, v.v.

@mixin flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
}

3. Nesting (Lồng nhau)

SASS cho phép bạn lồng các CSS selector lại với nhau, giúp mã code dễ đọc và tổ chức hơn. Điều này giúp giảm độ lặp lại và làm cho mã code trở nên rõ ràng hơn.

.navbar {
  background: black;
  .nav-list {
    display: flex;
  }
}
